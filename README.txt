نسخه‌ی اصلاح‌شده برای GitHub Pages

فایل index.html را در ریشه‌ی مخزن Portfolio-Masume، جایگزین index.html قبلی کنید.
فونت، عکس‌ها و رزومه داخل همین فایل قرار دارند؛ پوشه‌ی assets لازم نیست.
فایل ZIP را به‌عنوان سایت آپلود نکنید: ابتدا آن را باز کنید و index.html داخلش را آپلود کنید.
پس از Commit و پایان انتشار Pages، یک بار صفحه را با Ctrl+F5 بازخوانی کنید.
پروفایل فارسی و انگلیسی، عکس اصلی داخل رزومه، تصاویر واقعی سه پروژه و پیش‌نمایش رزومه داخل فایل هستند.
